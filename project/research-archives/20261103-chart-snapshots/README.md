- 对应的最新研究代码、参数配置、输入数据与逐笔账本当前未随本目录恢复，不能仅凭这些图复现结果。

- 2026年数据已被查看，只能作为已曝光历史观察，不是新的未见验证集。图中历史区间、成本和成交口径各不相同，不应横向混合比较。
- 部分图是条件标签、因子分组或机制诊断，不能解释为可执行组合收益。模拟初始资金、持仓和敞口不是实际个人账户记录。

- 原图保留原始标注，包括其中的旧审查表述；该表述不代表本次恢复已完成对应审查。
- 不新增或修改任何现有研究注册记录、因子准入状态或策略结论。原有Skill和已发布研究保持不变。
